Deployment using Heroku

1. signup.heroku.com/login -- website
2. After registering on email and after loging successfully, we get 2 options 
   1. Create a app and 2. Create a new team
3. Select Create a new app option
4. Enter your app-name and choose a region and then click on Create app
5. Install Heroku package globally on machine -- npm i -g heroku
6. Check version of heroku --- heroku -v
7. On terminal run command -- heroku login and press Enter
8. A window will pop up asking for approval. Then press yes.
9. Once logged in, You will get message as 'Logged in as username'
10. Add postgres database on heroku and for that enter command
    -- heroku addons:create heroku-postgresql:hobby-dev -a yourappname
11. Database will be created with autogenerated name 
12. Refresh heroku dashboard and you will see Installed add-ons
13. Click on resources and then click on database (which we created), we will redirected to page of Databse , where we can Check
database status which will be available and under settings tab we will get credentials

14. Now go to terminal of your project and enter command
    -- heroku git:remote -a yourappname
15.heroku config:set NPM_CONFIG_PRODUCTION=false
16. heroku config:set NODE_ENV=production
17. heroku config:set STAGE=prod
18. By using same command add database credentials which are generated to env file
   -- heroku config:set DB_HOST=host
   -- heroku config:set DB_PORT=5432
   -- heroku config:set DB_USERNAME=user 
19. Now to check , Go to heroku dashboard--> settings --> Reveal config vars (You will get all variables)
20. Create Procfile 
21. Git add, Git commit and git push -f heroku HEAD:master
22. Check logs using command -- heroku logs --tail
23. Now go to heroku dashboard , and click on 'Open app' and run the apis with the prod url in postman
